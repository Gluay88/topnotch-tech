# gh-pages: do not delete this branch

This branch holds the **built website** for the GitHub Pages backup:
https://gluay88.github.io/topnotch-tech/

- Deleting it takes the backup site offline.
- Don't edit or merge it by hand. It is generated and fully replaced on every
  deploy, so manual changes are lost.
- The source code lives on `main`. To update this branch, run
  `npm run deploy:pages` from `main`.
